# Steps to perform functional verification of original design with Questa simulation tool

Follow the instructions in the Questa-step-by-step.pdf file. This assumes that original verilog design files, not customized for VLSI with VDD and VSS, 
would be copied to the folder where the testbenches are. The testbenchs include several combination of operands to verify the design through functional simulation.
